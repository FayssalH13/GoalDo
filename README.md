# GoalDo

تطبيق أهداف ومهام مع ودجت على الشاشة الرئيسية (النسخة 0.1).

## طريقة الحصول على APK
1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`) إلى المستودع.
3. افتح تبويب **Actions** وانتظر انتهاء "Build APK" (3-8 دقائق).
4. افتح التشغيلة، ونزّل **GoalDo-debug-apk** من قسم Artifacts، وفك الضغط للحصول على `app-debug.apk`.
5. انقل الملف إلى هاتفك وثبّته.
